1. Context

Orbitra Reroute is an AI agent that pre-reroutes refrigerated poultry shipments (Santos, Brazil → Jebel Ali, UAE) when Gulf disruption (Hormuz, Red Sea, Bab-el-Mandeb) blocks the original route. The agent scores risk, builds a provider workbook, and presents Trade Operations with a recommended alternative port.

The Situation Room screen in our Trade Ops Desk UI shows a live 3D spatial world of the recommended port. When the agent recommends Jeddah, the Jeddah world loads; when it recommends Salalah, the Salalah world loads. The world thumbnail also appears on the risk card.

You are generating these worlds using Marble by World Labs (marble.worldlabs.ai). This is the W1 deliverable — hand-generated, cached worlds.

Deadline: 18 Oct 2026 · 21:30 GST
Worlds must be ready before the P1 integration checkpoint. Jebel Ali is optional — focus on Jeddah and Salalah first.

3. How to Generate in Marble

1
Open marble.worldlabs.ai and sign in.
2
Create a new world → paste the prompt from section 2 → generate.
3
Once generated, click Share → copy the share link. This is the marble_url.
4
Right-click the world thumbnail image → Copy image address (or inspect element). This is the thumbnail_url.
5
Test the share link in a logged-out / incognito browser — it must open without requiring a login. If it prompts for login, change the sharing setting to "Anyone with the link".
6
Fill in config/worlds.json (see section 4 below) and push / share the file.

4. What to Deliver — config/worlds.json

Open config/worlds.json in the repo. For each world you generate, fill in the two highlighted fields:

{ "worlds": [ { "id": "jeddah-port-01", "port": "Jeddah", "scope": "port", "title": "Jeddah Islamic Port — Container Terminal & Reefer Yard", "marble_url": "https://marble.worldlabs.ai/world/<YOUR-WORLD-ID>", ← paste share link here "thumbnail_url": "https://...", ← paste thumbnail URL here "source": "marble_app", "link_verified_at": "2026-10-18T<TIME>Z" ← timestamp when you verified the link }, { "id": "salalah-port-01", "port": "Salalah", ... "marble_url": "https://marble.worldlabs.ai/world/<YOUR-WORLD-ID>", "thumbnail_url": "https://..." } ] }
Only fill in marble_url, thumbnail_url, and link_verified_at. Leave all other fields exactly as they are in the file — the app reads the existing structure.

5. Important Notes

  • Share links must work logged-out. Test in incognito before submitting. The demo judge will open them without a World Labs account.
  • Thumbnail URL must be a direct image URL (ending in .jpg, .png, or similar) that loads without authentication. If the CDN URL requires a session token, let us know — we'll use a placeholder.
  • The worlds are labelled in the UI as: "AI-generated spatial approximation — verify with provider / port authority." — this is a non-negotiable hackathon guardrail.
  • Port accuracy is not critical — the worlds are illustrative. Focus on getting share links that open cleanly.
  • If Marble generation is slow, prioritise Jeddah first, then Salalah. Jebel Ali only if both are done with time to spare.
